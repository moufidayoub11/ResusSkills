# Professor UI sources

- beUI free components obtained through the beUI component registry: button, input, checkbox, switch, select, tabs, table, animated-sidebar, center-morph-modal, drawer and animated-toast-stack. Source links remain in the component headers. Adaptations add server-controlled table sorting, French labels, scoped portals and dashboard styles.
- React Bits Stepper and AnimatedList are adapted from the official ts-tailwind components at https://github.com/DavidHDev/react-bits. License retained in components/professor/react-bits/LICENSE.md (MIT with Commons Clause).
- React Aria Components provides calendar keyboard and range-selection behavior.
- Apache ECharts provides scientific charts and native SVG/Canvas export rendering.

Existing shadcn components remain for the public/student experience and are not imported by the new professor components.
